How to use the word counter

Type directly into the box or paste text from another document. The counts update automatically, so there is no submit button and no waiting. Use Clear text when you want to start again.

What does this tool count?

The tool reports words, all characters, sentences, paragraphs, and characters excluding whitespace. Reading time is estimated at an average pace of 225 words per minute.

Is my writing private?

Yes. Counting happens locally with JavaScript in your browser. The text you enter is not uploaded or stored by this tool.
