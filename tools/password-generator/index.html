How to generate a strong password

Choose a length and the character types you want, then select Generate new password. Longer passwords with a mix of lowercase letters, uppercase letters, numbers, and symbols are generally harder to guess.

Why use a random password generator?

People tend to create predictable passwords. A cryptographically random generator avoids common words and personal patterns, producing a unique password that is more resistant to guessing attacks.

Is this password generator safe?

Passwords are generated locally with the Web Crypto API and are never sent to our servers. Store each password in a trusted password manager, and never reuse passwords across accounts.
